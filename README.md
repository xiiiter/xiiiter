## 🧩 Cases (produtos privados/comerciais)

Código fechado por serem produtos de clientes/comerciais — descrição técnica e demo abaixo.

### MonitorBoard — Plataforma de Gestão Empresarial
App desktop (Tauri + React 19) integrado a uma API REST modular em NestJS com 21 módulos: tarefas, calendário, equipes, projetos, OKRs, relatórios, financeiro, RH, recrutamento e notificações.
Segurança de ponta a ponta: JWT (access/refresh), 2FA via TOTP, RBAC, rate limiting, Helmet, CORS por allowlist, logs de auditoria.
`Tauri` `React` `NestJS` `Prisma` `PostgreSQL` `Redis` `Docker`

### NeuralTrader — Motor de Sinais de Trading Algorítmico
API FastAPI orientada a eventos, execução automática via MetaTrader 5. Motor próprio ("4 camadas + 6 gates + score") combinando regime de mercado, Smart Money Concepts e estrutura de risco. Gestão de risco automatizada (Position Guard) e backtest determinístico com validação out-of-sample.
`Python` `FastAPI` `asyncio` `Pydantic v2` `pandas-ta` `WebSocket`

### AçõesJá — Web App Financeiro
Next.js App Router com RBAC no middleware (cookies de token, cargo e tier), separando rotas públicas, autenticadas, premium e admin.
`React 19` `TypeScript` `TailwindCSS` `React Query` `Recharts` `Zod` `Radix UI`

### Plataforma de Inteligência de Mercado
Descobre empresas por nicho/cidade e analisa presença digital (site, SSL, SEO, WhatsApp, redes sociais, velocidade), gerando um Score de Oportunidade de 0-100. Cache com TTL, coleta incremental, backoff/jitter, circuit breaker, CSRF, security headers.
`Next.js` `TypeScript` `Prisma` `PostgreSQL` `shadcn/ui` `Python`
